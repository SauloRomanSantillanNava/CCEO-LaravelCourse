# Laravel Training Course - CCEO

This repository contains the code, exercises, notes, and projects developed throughout the **Laravel training course provided by CCEO**.

The purpose of this repository is to serve as a **learning log and technical reference**, documenting progress over time as new topics, best practices, and backend implementations are added.

---

## 📚 About This Repository

This project is intended to grow progressively during the training process.

As the course advances, this repository will include:

- Laravel fundamentals
- MVC architecture implementation
- Routing and controllers
- Blade templating
- Database management with Eloquent ORM
- Migrations and seeders
- Form handling and validation
- Authentication and authorization
- RESTful API development
- Best practices and clean architecture principles
- Real-world mini projects
- Personal notes and learnings

This makes the repository not only a code base, but also a **knowledge base** for future reference.

---

## 🛠 Technologies

Currently used technologies:

- **PHP**
- **Laravel**
- **MySQL / MariaDB**
- **Composer**

Future additions may include:

- API integrations
- Authentication systems (JWT, Sanctum)
- Testing tools (PHPUnit)
- Queues and background jobs
- Deployment and DevOps practices

The main goal of this repository is to strengthen practical knowledge of Laravel through hands-on exercises and guided implementations as part of the CCEO training program.
